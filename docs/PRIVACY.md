# データの取り扱い

アプリに入力した氏名・派遣期間・薬・服用・入手・消失・通知設定は端末内の保存領域に保管します。開発者のサーバーへ自動送信する機能、アクセス解析、広告SDK、アカウント登録は含みません。

PDFの共有・メール添付・バックアップ保存・復元は、利用者が操作した場合に実行します。出力には個人情報・健康情報が含まれるため、送付先と保管場所を確認してください。バックアップ自体はアプリで暗号化していません。端末のロックと安全な保存先を利用してください。

OS通知には薬の服用や確認の内容が表示されます。ロック画面への表示可否は端末の通知設定で管理できます。

Androidではアプリの自動バックアップを無効にする設定、iOSではアプリのDocuments領域を自動クラウドバックアップ対象から除外する設定を含みます。明示的に書き出したPDFやバックアップの保管先は利用者が選択します。

アプリの削除や端末の初期化で記録を失う場合があります。必要な記録は削除前にバックアップを保存してください。

不具合報告へ、実際のバックアップ・氏名・健康情報を添付しないでください。画面を共有する場合は個人情報を隠してください。

この説明は同梱ソースの動作を記述しています。ストア申告や正式なプライバシーポリシーを公開する際は、実際の配布内容・運営者・問い合わせ先に合わせて確認・追記してください。
