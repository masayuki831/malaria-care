# 利用条件の方針と公開時の表示

同梱のLICENSE.mdは、指定された方針に合わせた独自ライセンスの文案です。

- 現在の版は無償利用可。業務内での利用も可。
- ソフトウェアの改変・改変版の提供は禁止。
- 販売・再販売・有償配布は禁止。
- 未改変・無償の場合も、第三者によるAPK等の再配布は禁止。正規配布元のリンク共有は可。
- 将来新しく提供する版・機能・サービスは、有料化や条件変更が可能。変更前に取得した版への遡及請求は定めていません。
- アプリ設定、入力データ、生成したPDFやバックアップの編集・共有は、ソフトウェア改変の禁止と区別します。

ビルド・署名に必要な環境設定だけの変更は、同梱のiPhone向け設定手順が実行できるよう、機能・外観・権利表示を変えない範囲で認めています。その他の改変を許可する場合は、権利者が別途明示して許諾します。

GitHub Desktopで新規リポジトリを作る際のLicenseは**None**を選び、同梱の独自LICENSE.mdをそのまま置いてください。MITやApache等のテンプレートへ置き換えると、意図した改変・再配布禁止と異なる条件になるため使用しません。一般的なオープンソースライセンスとしては紹介しません。

Releasesでは、利用条件の要点を説明欄へ記載し、APKと一緒にLICENSE.mdも添付してください。取得・利用する前に条件を確認できる位置で案内します。APK本体は再ビルドしていないため、この文書の内容を確認する新しい同意画面をアプリ内へ追加したものではありません。

第三者ライブラリ・フォントの元のライセンスは維持します。また、公開リポジトリの閲覧やフォークはGitHub規約に従うため、ライセンスでGitHubのフォーク機能そのものを無効化することはできません。

本書は方針の説明であり、個別の事案における法的有効性を保証するものではありません。公開時の表示、取得・同意の方法、実際の運用も含めた法的な確認は別途必要です。
