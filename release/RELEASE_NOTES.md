# Malaria Care 0.8 — 利用者検証版

## 利用条件

本版は無償で利用できます。改変・再販売は禁止します。未改変・無償でもAPK等の再配布はできません。他の方には、この正規配布元のリンクを共有してください。

将来新しく提供する版・機能・サービスは有料化等の条件変更を行う場合があります。添付のLICENSE.mdを確認し、同意できる場合に取得・利用してください。第三者ライブラリには元のライセンスを適用します。

## Android版のインストール

添付のmalaria-care-v0.8.apkをAndroid端末で開いてインストールしてください。更新時はアンインストールしないでください。新規利用時の通知は2種類ともOFFで、設定でONにできます。

## 主な機能と変更

- カレンダーで服用済み・飲み忘れ・遅延服用を管理
- 入手・消失と残数・在庫切れ予測
- 服用リマインダーと翌日の服用確認
- 対象期間・報告日を選んでPDF作成・保存・共有・メール添付
- バックアップの保存・復元
- モック検証機能とモード表記を削除

服用量・頻度・遅延時の対応は、処方医など医療担当者の指示を優先してください。不具合の報告に個人情報・健康情報や実際のバックアップを添付しないでください。

## iPhone版

iPhone用のソースとビルド手順はCodeに含みますが、署名済みアプリはまだ配布していません。このAndroid APKやソースZIPはiPhoneにインストールできません。Apple側の登録とTestFlight等での配布準備が必要です。

## 検証

Android APKは既存の0.8.0+15を継続し、更新用署名を保持しています。配布APKはAndroid 12エミュレーターで確認済みです。GitHub向けソースではiOS用処理も含む148項目のテストと静的解析が成功しています。iOSのビルドと実機確認、GitHub Actions上での実行は未実施です。

SHA256SUMS.txtでAPKのハッシュを確認できます。
